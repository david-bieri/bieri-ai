Cross-platform session handover

PlatformReads state fromWrites state to
ClaudeProject Knowledge ({DOMAIN}_SESSION_NOTES.md)Project Knowledge at session end
ManusAttached repo (domains/{domain}/SESSION_NOTES.md)Commits + pushes to repo before task ends

This enables cross-platform continuity: start in Claude, note a blocker, pick up in Manus (or vice versa).

Core rules

Read {DOMAIN}_SESSION_NOTES.md before doing anything in a new session — on any platform.
Write {DOMAIN}_SESSION_NOTES.md before ending any substantive session — on any platform.
Any skill change must update SKILLS_MANIFEST.md in the relevant domain before the session closes.
Skills MUST be written in platform-agnostic Markdown (skill.md). Use adapters to generate platform-specific formats.
Run the appropriate validator after wrapping: audit_skill.py (Claude) or quick_validate.py (Manus).
